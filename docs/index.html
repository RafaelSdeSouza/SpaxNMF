SpaxNMF

Spatially aware NMF for integral-field spectroscopy

Recover component spectra and spatial structure from IFU cubes

SpaxNMF fits non-negative component spectra together with component-weight maps, combining smooth spectral regularization, Gaussian spatial coupling, and optional sparse priors for compact sources.

Get Started See the Benchmark

What the spatial model adds

  • Shared non-negative component spectra recovered from the full cube.
  • Gaussian spatial coupling on component-weight maps for extended structure.
  • Optional sparse priors for compact-source components such as GC-like signals.
  • Real-cube diagnostics against PCA and vanilla NMF under matched preprocessing.

The full objective, kernel weighting, and optimization details are documented on the Model page.

Data View Spaxels × wavelength

Built around matrix factorization after reshaping IFU cubes.

Spatial Prior Gaussian kernel

Nearby spaxels are coupled with PSF-like distance weighting.

Compact Sources Optional sparse maps

Selected components can be driven toward GC-like or point-like structure.

Interpretability first

The factorization is non-negative, so each spaxel is reconstructed as a positive combination of shared component spectra and spatially varying component weights.

Designed for real cubes

The package includes helpers for IFU reshaping, metadata preservation, and comparative diagnostics against PCA and vanilla NMF on the same target.

Method development ready

The current implementation supports smooth spectra, weighted spatial priors, and sparse compact-source components inside the same torch optimization loop.

Core Factorization

Factorization

Shared spectra, spatially varying weights

\[ X \approx AS \]

X is the spaxel-by-wavelength matrix, A is the component-weight matrix, and S contains the component spectra.

Spatial term

Weighted coherence between neighboring spaxels

\[ w_{ij} = \exp\left(-\frac{d_{ij}^2}{2\sigma^2}\right) \]

This term discourages noisy salt-and-pepper maps by penalizing strong changes between nearby component weights while allowing distant spaxels to decouple.

Quick Workflow

Real-Cube Benchmark

NGC1512 galaxy + compact sources + sky

The current benchmark uses NGC1512_cube_mockGCs.fits, a mixed IFU cube containing extended galaxy structure, compact GC-like sources, and sky contamination in the same field. The comparison applies the same outer-spaxel sky subtraction and matched preprocessing before fitting PCA, vanilla NMF, and the mixed spatial+sparse model. 

<p class='benchmark-inline'>On the saved NGC1512 benchmark, the mixed spatial+sparse fit reduces the vanilla NMF MSE from 0.000399 to 0.000322 while raising the designated compact-component top-1% concentration from 0.057 to 0.113.</p>

Use the benchmark page for the full figure, saved metrics, and the exact run configuration used to generate them.

Open the real-cube benchmark

What the benchmark is for

This benchmark is intended as a technical validation target rather than a front-page showcase. It is useful for checking whether the mixed spatial+sparse prior improves compact-component concentration and preserves acceptable reconstruction quality under matched preprocessing.

  • PCA remains the rank-(k) squared-error baseline.
  • Vanilla NMF provides the non-negative comparison without spatial coupling.
  • SpaxNMF adds Gaussian spatial smoothing and optional sparse compact-source components.
  • The full figure, saved metrics, and run settings live on the benchmark page.

Use the benchmark page when you want the detailed diagnostic, not the main landing-page overview.

Main Entry Points

Fit models

spax_nmf() fits the torch model and returns spectra, weights, reconstructions, and optimization history.

Reshape data

cube_to_matrix() and matrix_to_cube() move between IFU cubes and the matrix view required by the optimizer.

Inspect results

component_map(), component_spectrum(), plot(), and plot_reconstruction() provide quick diagnostics.

Benchmark on toy and real targets

The website includes a controlled toy sanity check for standalone NMF and a real mixed galaxy+GC+sky benchmark under matched preprocessing.
